# 蒸汽疏水阀在线监测系统 · 管理平台 HTML 交互原型

## 打开方式

直接用浏览器（Chrome / Edge）打开 `index.html` 即可运行，无需安装任何依赖。
前端基于 Vue 3（CDN 全局构建）+ ECharts 5，hash 路由单页应用，全部数据为内置模拟数据（模拟时钟：现实 1 秒 ≈ 平台 50 分钟，页面呈现实时滚动效果）。

## 泄漏诊断与基线学习（与《诊断模型优化方案V4.md》同步）

- **传感器**：PT100 热电阻，进出口管壁贴装，双通道 60s 同步采集；
- **统一诊断口径**：所有页面共用同一判定入口 `MOCK.baseline.diag()`——取最近 **30 分钟稳定生产窗口均值**（进口极差 <5℃ 且出口极差 <5℃，回溯 3 小时取最近一个满足条件的窗口）与**人工学习基线**比对，不用瞬时采样值；
- **泄漏策略**（倒立桶 / 热力型，浮球式连续排放不适用，输出「疑似泄漏」交人工确认）：出口均值 > 出口基准 +10℃ 连续 3 周期 → 泄漏报警；出口均值 > 基准 +25℃ 或 温差均值 < 基准×65% 连续 2 周期 → 严重报警；
- **堵塞策略**（全阀型适用）：温差窗口均值 > 温差基准 25% → 轻度堵塞；> 35% → 重度堵塞；
- **前置门控**：停产、数据异常（双通道冻结/跳变）不参与诊断；浮球式仅适用温差判据；
- **基线学习**：生产稳定 / 非排水时间 200 采样点 → 出口基准 + 温差基准；每 15 天自动重算；新基线相对原基线上升 ≥3℃ 需人工确认才生效（拒绝则保持原基线）；每次变更留痕，累计上升 ≥5℃ 触发趋势预警（提示疑似故障数据污染基线）；
- **人工标注学习**（推荐方式）：曲线标注式基线学习——Y 轴为进口温度 Ts / 出口温度 Tc / 进出口温差 ΔT 三条曲线（1 分钟粒度 · 最近 4 小时），点「开始数据标记」出现左右两个游标卡尺，横向拖动框选「生产稳定 · 非排水时间」区间，确认后该线段变为黄色；可多段批量标注，点「开始数据学习」按全部标注样本计算基准。选区自动做稳定性门控（Ts/Tc 极差均 <5℃ 为稳定窗口，含排放脉冲/波动段标红提示剔除）；另保留「自动学习 200 点」备用方式；
- **交互入口**：设备台账「基线标注」按钮或「档案」→「基线学习」页签；诊断分析「诊断策略与基线配置」页可维护策略参数并集中处理基线待办；顶栏「基线待办」徽标直达。

## 模拟数据说明

- 45 台疏水阀（3 个区域：动力区域 / 酿造区域 / 包装区域），状态分布：正常 32 / 泄漏 5 / 阻塞 3 / 停产 4 / 数据异常 1；
- 每台设备 24h 波形按状态与阀型特征生成：间歇排放型（倒立桶/热力型）= 非排水期平稳低位 + 周期排放脉冲（约 35min），浮球式 = 连续排放小幅纹波；泄漏 = 双高小波动、阻塞 = 温差持续走阔、停产 = 双降；
- 基线取值原则：健康设备取本机实测中位数（P50，对排放脉冲不敏感），故障/停产设备沿用同型号健康基准，因此"相对基准偏差"本身即故障指示量；相对基准档位分布：正常 33 / 重度堵塞 3 / 严重泄漏 3 / 疑似泄漏 2（浮球式）/ 不适用 4；
- 判定依据文案与诊断策略页、设计文档保持同源一致。

## 浮球式泄漏诊断（2026-09-17 新增）

浮球式为连续排放型（无"非排水时间"窗口，出口温度基准偏高），泄漏判据改为「进出口温差相对温差基准的比值」单判据分档，
**倒立桶 / 热力型的原判据与参数完全不变**：

| 档位 | 判据（每 20min 评估一次，取最近 30min ΔT 均值 ΔT̄） |
|------|------|
| 正常 | R = ΔT̄/ΔT_base ≥ 75% |
| 泄漏报警（初期） | 65% < R < 75%，连续 3 次 |
| 严重泄漏报警 | R < 65%，连续 2 次 |

入口：诊断策略与基线配置 → 浮球式页签（深链 `#/diag/strategy/浮球式`），含判定流程、参数维护、与间歇排放型差异对照、
全 15 台浮球式设备评估明细（比值 + 连续次数）。监测详情页对浮球式设备新增「泄漏评估序列」（连续次数进度 + 最近 8 次评估落档），
ΔT 曲线叠加初期泄漏线（基准 75%）与严重泄漏线（基准 65%）。告警规则页新增 2 条浮球式专属规则。
演示样本：ST-2024-013 初期泄漏（R≈0.70 → 泄漏报警）、ST-2024-028 严重泄漏（R≈0.25 → 严重泄漏报警）。
